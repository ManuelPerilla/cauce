# Solución de problemas

| Problema | Qué revisar |
| --- | --- |
| No hay canciones disponibles | Importa archivos, confirma que aún existen y asigna el género elegido. Un enlace externo no cuenta como audio local. |
| La sesión se detiene | Lee el motivo: puede agotarse el género, impedirlo la separación de artistas o estar desactivadas las repeticiones. Ajusta la regla que tú quieras. |
| Error al reproducir | Comprueba que Windows admite el archivo y su códec. MP3, WAV o M4A no garantiza que cualquier archivo concreto sea válido. |
| Inicio de sesión deshabilitado | Es normal sin un broker y registros reales. La música local no necesita cuenta. |
| La ventana desaparece al minimizar | Restaúrala desde la bandeja o con Alt+Shift+C si el atajo está disponible. |
| Datos ilegibles o de versión posterior | Sigue el aviso de la aplicación. Conserva una copia; no sobrescribas una biblioteca de esquema posterior. |

Para reportar un fallo, abre **Soporte → Reportar un error** e indica pasos, resultado esperado y versión. Revisa el borrador y excluye tokens, contraseñas, rutas privadas y música. Si Windows bloquea la ejecución, no desactives sus protecciones para eludirlo.
