# Controles de Cauce

- **Biblioteca → Añadir archivos**: importa referencias a MP3, WAV y M4A. Edita artista y género cuando falten.
- **Escuchar**: inicia, pausa o avanza la reproducción; selecciona género y reglas. Si no existe una canción elegible, Cauce explica el motivo.
- **Abrir enlace**: abre una referencia HTTPS en el servicio correspondiente. No reproduce un catálogo integrado.
- **Modo compacto**: deja a mano los controles principales. Al minimizar, usa la bandeja de Windows para restaurar o salir. Alt+Shift+C restaura la ventana cuando Windows permite registrar el atajo.
- **Apariencia**: cambia tema, movimiento y transparencia.
- **Guía**: repite el tutorial y consulta las preguntas frecuentes.
- **Soporte**: exporta o borra datos locales y prepara un reporte de error.

Los reportes se abren como borradores en GitHub; revisa su contenido antes de enviarlos. Cerrar la ventana termina la aplicación y guarda las preferencias pendientes.
