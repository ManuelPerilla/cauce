# 代码签名策略

SignPath Foundation 审批目前仍在等待中。

启用签名后：

**Free code signing provided by SignPath.io, certificate by SignPath Foundation.**

只有来自官方 `ManuelPerilla/ngmusic` 仓库并通过批准的自动化 pipeline 构建的产物可以签名。

不得使用项目签名身份为无关项目、不可验证的本地修改二进制或第三方专有软件签名。

当前角色：
- Committer: ManuelPerilla
- Reviewer: ManuelPerilla
- Signing approver: ManuelPerilla

外部 PR 必须经过维护者审查。每次签名都需要人工明确批准。

拥有仓库或签名权限的账户必须使用 MFA。签名私钥不得进入 Git、日志或构建产物。
