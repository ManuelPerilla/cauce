# 故障排除

| 问题 | 检查方法 |
| --- | --- |
| 没有可用歌曲 | 导入文件，确认文件仍然存在，并补充所选曲风。外部链接不是本地音频。 |
| 会话停止 | 阅读原因：可能没有同曲风歌曲、艺人间隔阻止继续，或禁止重复。按自己的意愿调整规则。 |
| 播放错误 | 检查 Windows 是否支持文件及其编码。MP3、WAV 或 M4A 扩展名不能保证每个文件有效。 |
| 登录不可用 | 没有真实身份代理和注册时，这是预期行为。本地音乐无需账户。 |
| 最小化后找不到窗口 | 从通知区域恢复，或使用可用的 Alt+Shift+C 快捷键。 |
| 曲库无法读取或格式较新 | 按应用提示操作，保留副本，不要覆盖较新版本格式。 |

在 **Soporte → Reportar un error** 中说明复现步骤、预期结果和版本。检查草稿，移除令牌、密码、私人路径和音乐文件。如果 Windows 阻止执行，请不要关闭保护机制来绕过限制。
