# 界面操作

- **Biblioteca → Añadir archivos**：添加 MP3、WAV 和 M4A 引用，必要时补充艺人和曲风。
- **Escuchar**：播放、暂停或切换下一首，选择曲风和规则。没有符合条件的歌曲时，Cauce 会解释原因。
- **Abrir enlace**：在对应服务中打开 HTTPS 引用；应用没有集成流媒体曲库。
- **Modo compacto**：保留主要播放控制。最小化后，从 Windows 通知区域恢复或退出。当 Windows 允许注册快捷键时，Alt+Shift+C 可恢复窗口。
- **Apariencia**：调整主题、动画和透明度。
- **Guía**：重看教程和常见问题。
- **Soporte**：导出或清除本地数据，并准备错误报告。

错误报告以 GitHub 草稿打开，提交前需要自行检查。关闭窗口会退出 Cauce，并保存尚未写入的偏好设置。
