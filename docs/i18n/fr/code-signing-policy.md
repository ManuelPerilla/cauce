# Politique de signature de code

L'approbation de SignPath Foundation est en attente.

Lorsque la signature sera active :

**Free code signing provided by SignPath.io, certificate by SignPath Foundation.**

Seuls les artefacts issus du dépôt officiel `ManuelPerilla/ngmusic` et du pipeline automatisé approuvé peuvent être signés.

Rôles actuels :
- Committer : ManuelPerilla
- Reviewer : ManuelPerilla
- Signing approver : ManuelPerilla

Les PR externes doivent être revues avant merge. Toute demande de signature nécessite une approbation humaine explicite.

Les comptes ayant accès au dépôt ou à la signature doivent utiliser MFA. Les clés privées de signature ne doivent jamais être stockées dans Git, les logs ou les artefacts.
