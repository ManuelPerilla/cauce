# Commandes de l’interface

- **Biblioteca → Añadir archivos** : ajoutez des références MP3, WAV et M4A, puis complétez artiste et genre.
- **Escuchar** : lancez, mettez en pause ou avancez la lecture ; choisissez le genre et les règles. Cauce explique l’absence de morceau admissible.
- **Abrir enlace** : ouvrez une référence HTTPS dans son service. Aucun catalogue de streaming n’est intégré.
- **Modo compacto** : gardez les commandes essentielles visibles. Une fenêtre minimisée se retrouve dans la zone de notification. Alt+Shift+C restaure la fenêtre si Windows autorise ce raccourci.
- **Apariencia** : choisissez thème, animations et transparence.
- **Guía** : relancez le tutoriel et consultez les questions fréquentes.
- **Soporte** : exportez ou effacez les données locales et préparez un rapport.

Un rapport ouvre un brouillon GitHub que vous devez vérifier avant envoi. Fermer la fenêtre quitte Cauce et enregistre les préférences en attente.
