# Cauce terminal source reference

This guide describes archived source, not the current desktop application. For supported behavior and packaging, read the [Cauce README](../../README.md) and [documentation index](../../docs/README.md).

| Archived path | Purpose |
| --- | --- |
| `archive/src/Cauce.Terminal` | Terminal command loop, playlists, service integration and playback prototype |
| `archive/src/Cauce.Terminal.Configurator` | Windows configuration utility for the terminal prototype |
| `archive/src/Cauce.Terminal.Setup` | Graphical installer bootstrapper prototype |
| `archive/src/Shared` | Configuration models shared by the terminal tools |
| `archive/packaging/windows` | WiX installer sources for the terminal prototype |
| `archive/build` | Preserved development and packaging scripts |

These components are kept for reference and are not included in the maintained desktop builds. Their browser-based service playback, account setup and installer behavior must not be presented as features or distribution channels of the current Cauce application.

Current development uses the scripts in the repository's root `build/` directory. Current account configuration is documented in [Cauce accounts](../../docs/cauce-accounts.md).
